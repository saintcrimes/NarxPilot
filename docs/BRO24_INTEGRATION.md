## Что подтверждено

На публичном сайте Bro24 описаны ответы по добавленной информации и подключения Telegram-бота/подходящего Telegram-аккаунта в бета-режиме с ограниченным доступом. Сайт отдельно предупреждает об ошибках AI и конфиденциальных данных. Источник: S1, проверено 31.10.2026.

В просмотренных открытых материалах не удалось подтвердить публичный API, SDK, веб-виджет, webhook-протокол или возможность обращения помощника к внешним динамическим инструментам. Это **не утверждение, что таких возможностей у Bro24 нет**. Их нужно получить у владельца продукта или из доступной документации.

## Что реализовать сейчас

Создать собственный интерфейс адаптера. Он не должен утверждать совместимость с ещё неизвестным API.

```ts
type SupportProviderMode = 'disabled' | 'mock' | 'live';

type SupportContext = {
  organizationId: string; // определён серверной сессией
  userId: string;
  locale: 'ru' | 'uz';
  conversationId: string;
};

interface SupportProvider {
  readonly mode: SupportProviderMode;
  answer(input: {
    message: string;
    context: SupportContext;
  }): Promise<{
    text: string;
    sourceRefs: string[];
    generatedAt: string;
    requiresHuman: boolean;
    isDemo: boolean;
  }>;
}
```

Это описание контракта, не готовый вызываемый SDK. В реальном коде необходимы валидация входа, лимиты, timeout, обработка ошибок и тесты.

MockSupportProvider отвечает только на локальные демонстрационные вопросы; во всех ответах и статусе подключения видна надпись «Демо интеграции, Bro24 не подключён». Нельзя считать ответы mock реальным расходом кредитов Bro24 или реальными запросами клиентов.

## Наши разрешённые read-only инструменты

`get_product_offers(sku, location, quantity)` — текущие предложения с valid_until и условиями.

`get_market_snapshot(sku, location, period)` — проверенный аналитический снимок и ограничения.

`get_my_order_status(order_id)` — только заказ авторизованной организации/стороны, доступ проверяет наш backend.

`get_faq(topic)` — утверждённые правила сервиса, доставки, подтверждений и методики.

Никаких произвольных SQL, выгрузок всей базы, доступа по одному угаданному order_id и автономного изменения заказов. У инструмента отсутствует право «подтвердить за покупателя».

## Два возможных рабочих варианта

**Динамический API подтверждён:** создать LiveBro24Provider строго по реальной документации; настроить server-to-server авторизацию, роли, обновления и разрешённые инструменты. Поддержка ограничений зависит от фактических возможностей Bro24; нельзя предполагать их наличие.

**Доступны только материалы/FAQ:** использовать Bro24 для утверждённых общих вопросов. Для сегодняшней цены, остатка и личного заказа направлять к авторизованной карточке NarxPilot. Не обещать актуальный ответ по статичному файлу. Импортировать материалы только средствами, реально доступными в кабинете; неизвестный формат загрузки не выдумывать.

## Что необходимо для live

Документация endpoint и версии; способ авторизации и выдачи прав; модель организаций; форматы запросов/ответов; поддержка tools/webhooks; ограничения частоты и размера; политика обработки/хранения данных; sandbox; примеры ошибок; условия оплаты. Эти пункты нужны для интеграции, но не блокируют основной marketplace.

Для webhook проверка подписи и защиты от повтора реализуется **по документированному протоколу провайдера**, а не по произвольно выбранному заголовку. Дополнительно использовать уникальный message_id и идемпотентную обработку. При отсутствии надёжной схемы авторизации live выключен.

## Критерии приёмки

Цена в ответе совпадает с текущим API-результатом и имеет время/условия. Если источник недоступен — нет выдуманной цены. Пользователь организации A не получает заказ организации B. Повтор сообщения не создаёт повторный побочный эффект. При timeout есть безопасное сообщение/передача человеку. Подтверждённые действия требуют отдельного согласия в интерфейсе.

Не переносить все сырые сделки в общую базу ответов. Секреты Bro24 остаются на сервере; чувствительные данные минимизируются. Нужные русский и узбекский ответы проверяются реальными тестами, а не выводятся из списка языков сайта.

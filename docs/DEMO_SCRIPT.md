# Демонстрация на 3 минуты

Сценарий предназначен для запуска после успешной установки зависимостей и полного E2E. Этот документ не означает, что браузерный прогон уже выполнен; статус в VERIFICATION.md.

**До показа.** Проверить web/worker health, миграции и seed. Открыть http://localhost:3000. В каждой сцене остаётся DEMO_MODE. FAQ необязателен и по умолчанию выключен. Модель/ключ не требуются для закупки.

**0:00–0:20.** «Магазину нужно пять одинаковых смартфонов. Мы сравниваем точный SKU и полную стоимость, а затем сохраняем согласованные условия и результат». Выбрать «Магазин „Орион“». Не приписывать вымышленному магазину реальную историю.

**0:20–0:50.** Ввести `iPhone 15 128`. Открыть сравнение: пять вымышленных поставщиков, количество 5, цена единицы, доставка один раз, сборы, срок и источник. По желанию выбрать явную альтернативу для разницы стоимости. Без неё экономии нет.

**0:50–1:40.** Отправить заявку первому поставщику. Переключиться на Atlas Mobile, подтвердить условия. Покупатель принимает котировку: запас резервируется атомарно. Поставщик подтверждает отгрузку, покупатель — приёмку. Показать журнал событий и сохранённую версию условий.

**1:40–2:15.** Перейти к аналитике. Объяснить отдельно две медианы, продажи и остаток. Показать время/версию расчёта и таблицу. Одиночная текущая сделка может быть скрыта public-фильтром; для фактического прироста открыть аккаунт поставщика и «Мои данные». Не понижать пороги ради показа.

**2:15–2:35.** «Продано 500, 200, 100 из 1000 — осталось 200. Без цен нельзя сделать вывод, что товар подешевел». Показать проверку этого примера и отказ от прогноза. Не объявлять шаблон AI-анализом.

**2:35–3:00.** Назвать план пилота из HACKATHON_PLAN и ограничения: всё синтетическое; реальные поставщики, оплата и обученная модель не подключены. Если FAQ включён, открыть один общий вопрос и подчеркнуть: это локальная справка, независимая от аналитики.

Резерв для 2 минут вопросов: снимки заказа, конкурентный тест последнего товара, возврат/карантин, outbox и воспроизводимая история. Финансовые числа из плана — допущения, не выручка проекта. Презентация отдельным файлом в этом задании не создавалась.

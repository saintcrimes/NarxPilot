# Telegram Mini App

NarxPilot открывается внутри Telegram из кнопки меню бота «Открыть NarxPilot». Используются существующие главная страница, регистрация и кнопка «Попробовать демо». Telegram SDK отвечает за высоту окна, безопасные отступы, цвета и кнопку «Назад». Данные аккаунта Telegram не используются для входа: обычные серверные сессии и проверки прав сохраняются.

## Настройка на сервере

В `/opt/narxpilot/.env` добавьте `TG_BOT_TOKEN` из BotFather и, если нужен другой адрес, `TELEGRAM_MINI_APP_URL=https://narxpilot.software-engineer.online/`. Токен не помещать в `NEXT_PUBLIC_*` и GitHub. Локальный `.env` компьютера не переносится на сервер автоматически.

```bash
bash /opt/narxpilot/deploy/control.sh update </dev/null && bash /opt/narxpilot/deploy/control.sh telegram </dev/null
```

Команда настройки проверяет бота через `getMe`, вызывает `setChatMenuButton` и проверяет сохранённую кнопку через `getChatMenuButton`. Она выводит имя бота без токена. Откройте личный чат с этим ботом и нажмите «Открыть NarxPilot» в меню. Пользователь подтвердил работу существующего бота; обычное обновление сайта не меняет его webhook и не запускает новый polling-процесс.

Если нужен отдельный обработчик `/start` и `/help`, предусмотрена необязательная команда `bash /opt/narxpilot/deploy/control.sh telegram-bot`. Она запускает лёгкий сервис с ответом и кнопкой Mini App. Для уже работающего бота запускать её не требуется. Свободный диалог в Telegram не добавлен; существующая справка Bro24 остаётся внутри сайта.

Если код уже обновлён, достаточно `bash /opt/narxpilot/deploy/control.sh telegram`. При установленном Node.js 22 можно из корня проекта выполнить `node deploy/telegram.mjs`; `--check` проверяет только токен без изменения кнопки.

## Границы проверки

Настройка кнопки и обработчик `/start` покрыты восемью тестами с подставленным Telegram API: контракт, проверка результата, команды только в личном чате, таймаут, webhook-конфликт и отсутствие токена в ошибках. Локальный живой запрос 31 октября заблокирован сетью среды (`EACCES`), поэтому ключ и доставку настоящего ответа подтверждает запуск на сервере. Токен не передаётся web/worker: его получают только сервисы Telegram.

Диагностика: `bash /opt/narxpilot/deploy/control.sh logs telegram-bot`. Требуется один polling-процесс на токен. Если ранее настроен webhook другого сервиса, бот остановится с понятной ошибкой; существующая интеграция автоматически не удаляется. Offset хранится в памяти: при перезапуске последнее неподтверждённое обновление может получить повторный ответ. Сообщения и токены не журналируются.

Вход через Telegram, платежи и рассылки не добавлены. Кнопка запуска в профиле бота (Main Mini App) настраивается отдельно в BotFather; команда выше создаёт кнопку в меню личного чата. Мобильный Telegram WebView использует существующий вход; Telegram Web может ограничивать сторонние cookies, поэтому при проблемах с сессией используйте мобильное приложение или откройте сайт во внешнем браузере. Проверка на реальном устройстве пока не выполнена.

Официальные контракты: [Telegram Mini Apps](https://core.telegram.org/bots/webapps), [setChatMenuButton](https://core.telegram.org/bots/api#setchatmenubutton).

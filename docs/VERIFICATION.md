1. В среде с доступом к registry выполнить `npm install`, сохранить созданный lockfile и проверить закреплённые версии.
2. Выполнить lint/typecheck/unit, затем Node integration на пустой narxpilot_test_web. Python DB fixtures держать в другой test-базе.
3. Собрать и поднять Compose; проверить health и seed/повтор seed.
4. Выполнить desktop/mobile E2E с CHATBOT_ENABLED=false и true, проверить полный путь и отсутствие внешних запросов FAQ.
5. Только после стабильного P0 переходить к ML и реальным источникам; провести отдельные проверки production-безопасности и приватности.

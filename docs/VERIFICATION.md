## Исправления по результатам исполнения

Первый CI выявил четыре ошибки ESLint: диагностический CJS-скрипт получил узко ограниченную настройку lint, признак истечения предложения вычисляется сервером и покрыт тестом. Первый браузерный прогон обнаружил гонку в тесте: дополнительный параллельный GET /api/session мог заменить cookie и рассинхронизировать CSRF. Тест теперь наблюдает настоящий запрос браузера и проверяет каждое переключение аккаунта. Защита CSRF не отключалась; полный пользовательский путь сохранён.

Deployment-тесты проверяют домен без инъекций, сохранение ключей и паролей при повторе, буквальные $ в секретах, актуальные метаданные доступа, отказ от live/test базы, ограничение опубликованных портов, разделение ролей/ключей и принятие Caddy конфигурации HTTPS/basic_auth. Script-тесты с подставленными CLI не являются реальной установкой Docker через apt или полным восстановлением backup.

## Bro24 и приватные данные

Пользователь добавил BRO24_API_KEY в локальный приватный .env. Один разрешённый диагностический запрос был заблокирован локальной сетью (EACCES), до получения HTTP-ответа. Действительность ключа, формат ответа и контекст NarxPilot у провайдера **не подтверждены**. Ключ не печатался, не коммитился и не отправлялся в GitHub/CI.

Реализован запрос из bro24.md: фиксированный POST endpoint, X-API-Key и три поля client_id/channel/message. Путь к ответу задаётся явно через BRO24_REPLY_JSON_PATH; неизвестный формат не угадывается. Без настройки или при ошибке используется локальная справка. На сервере предусмотрена команда deploy/control.sh check-chat, выводящая статус и имена возможных полей без текста ответа/секретов. Аналитический LLM остаётся отдельным слоем; его живой ключ/модель также не проверялись.

## Публикация и локальные ограничения

Код опубликован в saintcrimes/NarxPilot, ветка main. Перед публикацией deployment-коммита проверено совпадение всех **109 файлов** по Git blob SHA. .env, .local, локальная PostgreSQL-база, caches и сгенерированные файлы исключены.

Изначально в рабочей папке не было Git-истории. Локальный git init сработал, но запись .git/config запрещена файловыми правами, а Git HTTPS недоступен. Коммиты и обновление ветки выполнены GitHub connector без force; успешный push через CLI не заявляется. Локальные npm-команды ранее завершались отсутствием зависимостей после EACCES к registry, Docker daemon недоступен. Проверки выполнены в разрешённом GitHub CI; локальная сетевая политика не менялась.

## Исправленные проблемы

- `EACCES /app/package.json`: исходники с закрытыми правами копируются с владельцем node/worker. Эта регрессия реально покрыта Docker-тестом.
- Остановка после Caddy `Valid configuration`: воспроизведено зависание stdin под PTY; одноразовые команды используют `--interactive=false` и закрытый stdin.
- Сайт был недоступен из-за Azure-портов и ACME timeout; пользователь затем подтвердил открытие сайта. HTTP Basic Auth убран по его явному запросу. Доступность домена снаружи и сертификат на его сервере агент напрямую не проверял.
- Регистрационные E2E сначала ошибочно искали label select; исправлен поиск по роли combobox. Window-тип Telegram fixture и тип CSS custom property графика исправлены; полный повтор прошёл.
- Загрузка HONOR учитывает ограниченную цепочку HTTPS-переходов между разрешёнными хостами. Все 12 фотографий проверены как raster и сохранены в GitHub вместе с настоящим обновлённым npm lockfile (`5c8350c56574b15df520594262f5b3023c1563fb`).

## Реальные интеграции и границы

- Пользователь подтвердил, что Telegram Mini App работает. Проверка SDK в CI использует fixture; настройка реального ключа из локальной среды блокировалась сетью EACCES. Работающий бот не перенастраивается обычным update. Дополнительный polling-ответ `/start` реализован, но включается отдельной командой и не удаляет чужой webhook.
- Bro24: документированный серверный адаптер реализован; живой ответ, ключ и JSON-путь не подтверждены из локальной среды (EACCES). При недоступности используется FAQ. Аналитический LLM независим.
- Данные демобазы синтетические. Фото идентифицируют настоящие модели; это не доказательство наличия товара у настоящего поставщика.
- Квитанция — документ заказа, не фискальный чек и не подтверждение оплаты. Сравнение ограничено текущими сопоставимыми предложениями платформы, минимум пять независимых поставщиков.
- Тарифные карточки отображают цены и глубину истории; платежи и применение подписочных ограничений пока не реализованы.
- Переведены основные интерфейсы; часть backend-текстов и подробных объяснений остаётся на русском. Нет подтверждения email, восстановления пароля и приглашений.
- Экспериментальная ML-модель не обучена; точность и интервалы не заявляются. Реальные поставщики, платежи, фискальный оператор и сторонние уведомления не подключены.

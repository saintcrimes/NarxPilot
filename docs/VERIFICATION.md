- `EACCES /app/package.json`: исходники с закрытыми правами копируются с владельцем node/worker. Эта регрессия покрыта настоящим Docker-тестом.
- Остановка после Caddy `Valid configuration`: воспроизведено зависание stdin под PTY; одноразовые команды используют `--interactive=false` и закрытый stdin.
- Azure/ACME timeout: пользователь затем подтвердил открытие сайта. HTTP Basic Auth убран по его запросу. Доступность его VM и реальный сертификат напрямую из этой среды не проверялись.

- В предыдущем продуктовом прогоне 14/16 E2E прошли; два теста обнаружили потерю проверенного локального ответа API при переводе справки. Исправлено объединение ответа и локализации, полный повтор дал 16/16.
